# 智灌珈田 · Paddy Irrigation Platform

面向水稻灌排的智能决策软件。输入当前田面水层与未来天气，给出今天该灌多少、排多少。

**网页版**：<https://app.paddy-intelligence.xyz>

## 能做什么

**迁移学习决策** — 内置全国六大稻作区的预训练模型（18 个权重）。选任意站点，模型自动匹配所属稻作区，无需自己训练即可出灌排建议。全国 2311 个气象台站都可用。

**整季评估** — 拿 2013–2020 的历史数据逐年回算，把模型和固定水层规则等策略并排比较：灌溉量、排水量、超 Hc 天数、缺水产量影响风险因子。

**智能决策** — 自己训练 PPO 模型，看奖励曲线、收敛诊断、逐年策略对比。

**人在回路** — 逐日核对模型建议与实际执行，把人的修正喂回去做行为克隆微调。

**数据生成** — 由历史气象与预报生成训练文件，支持简单干湿增广与 Richardson WGEN 两种方式。

## 首次使用

1. 打开软件，注册账号（首个注册的账号自动成为管理员）
2. 进「迁移学习」，站点框输入站名或省份，从下拉里选一个
3. 填当前田面水层，点「生成灌排决策」

软件自带 2311 个台站的基础信息和全部模型权重，**不联网也能出当日决策**。

需要历史气象数据（用于整季评估、训练、数据生成）时，软件会向服务器请求。这部分按账号角色开放：

| 角色 | 可下载的台站数 |
|---|---|
| 超级管理员 | 不限 |
| 管理员 | 10 个 |
| 普通用户 | 不开放 |

需要更高权限请联系管理员。

## 常见问题

**打开后一直转圈？**
首次启动要在用户数据目录建库，约 20 秒。

**整季评估提示"暂无历史逐日数据"？**
该站点本地没有历史序列。当日决策不受影响；需要整季评估请让管理员为你开通数据权限，或用「数据生成」自行准备。

**软件装在哪、数据存在哪？**
- macOS：`~/Library/Application Support/CropRLDecision/`
- Windows：`%LOCALAPPDATA%\CropRLDecision\`

卸载软件不会删除这个目录，你的模型和训练结果会保留。

**智能助手不能用？**
需要自备 DeepSeek API Key，填到上述数据目录的 `secrets.json`：

```json
{ "DEEPSEEK_API_KEY": "你的密钥" }
```
